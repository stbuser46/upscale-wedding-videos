# Exact pip delta between the public base image
#   pytorch/pytorch:2.7.1-cuda12.8-cudnn9-runtime
# and the project's verified local image seedvr2-cuda:v3.
#
# Installing these pins on the base image reproduces the verified SeedVR2
# environment exactly. Verified when generated: NO package version in the base
# image is changed by this list, so torch/torchvision/CUDA are never clobbered.
#
# Why this exists: RunPod pods have no Docker daemon, so a pod cannot run our
# image via `docker run`. Rather than push a 13.6 GB image to a registry, a pod
# runs the public base and is provisioned with this pinned delta plus the 6.2 MB
# already-patched /opt/SeedVR2 tree copied out of the verified image itself. The
# tree is copied rather than re-cloned so the pinned upstream commit and all
# three local patches (writer-color, streaming-prepend, unit-drop-leading) are
# byte-identical to what production runs.
#
# Regenerate with:
#   docker run --rm --entrypoint pip pytorch/pytorch:2.7.1-cuda12.8-cudnn9-runtime freeze | sort > /tmp/base.freeze
#   docker run --rm --entrypoint pip seedvr2-cuda:v3 freeze | sort > /tmp/ours.freeze
#   comm -13 /tmp/base.freeze /tmp/ours.freeze
